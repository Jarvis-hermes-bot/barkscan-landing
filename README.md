# BarkScan

Monitoreo biométrico y de hidratación en tiempo real para perros. Salud preventiva para tu mejor amigo.

## Stack técnico

- HTML5 + Tailwind CSS (CDN)
- JavaScript vanilla
- Node.js (servidor estático nativo con `http`)

## Instalación y arranque

```bash
# Clona el repo
git clone https://github.com/Jarvis-hermes-bot/barkscan-landing.git
cd barkscan-landing

# Arranca el servidor
node server.js
```

Abre http://localhost:3000 en tu navegador.
